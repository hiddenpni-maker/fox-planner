## 🇮🇷 معرفی کامل فاکس پلنر

**فاکس پلنر (`Fox Planner`)** یک اپلیکیشن موبایل (اندروید و وب) کاملاً **آفلاین، سبک و چشم‌نواز** است که برای دانش‌آموزان، دانشجویان و تمام افرادی طراحی شده که می‌خواهند بدون شلوغی و حواس‌پرتی، کارها، درس‌ها، جزوه‌ها و سلامت روان خودشان را یک‌جا مدیریت کنند.

### ✨ قابلیت‌های کلیدی نسخه فارسی / دوزبانه

- **🦊 راهنمای زنده قدم‌به‌قدم با حباب گفتگوی روباه:** هنگام اولین ورود، روباه شما را به تک‌تک بخش‌های واقعی برنامه می‌برد و اصطلاحات (پومودورو، XP، تنفس ۴-۴-۴-۴، PIN) را ساده و صمیمی توضیح می‌دهد.
- **📋 پلنر روزانه تمیز و سه‌پنلی:** شروع کاملاً خالی و شخصی (بدون تسک‌های اضافه) شامل تب‌های **برنامه‌ها**، **تقویم شمسی و مناسبت‌ها 📅** (ثبت امتحانات و ددلاین‌ها + مناسبت‌های دانشجویی و ملی) و **یادآورهای زمان‌بندی‌شده ⏰** (با ۳ لحن روباهی، انگیزشی و آرام + زنگ و Snooze).
- **🍅 تایمر پومودورو هوشمند:** تمرکز عمیق ۲۵/۵، ۵۰/۱۰، اسپرینت یا زمان دلخواه با اتصال مستقیم به تسک‌های پلنر و ثبت خودکار پیشرفت.
- **📓 دفتر جزوه و نوت‌برداری چندرسانه‌ای:** ترکیب متن، تیتر، هایلایت طلایی، چک‌لیست مرور، عکس از تخته/کتاب (گالری و دوربین)، ویدیو و فایل PDF کاملاً آفلاین روی حافظه دستگاه.
- **📊 نمودارهای زنده و انیمیشنی + حال‌سنج روزانه:** نمودارهای متحرک مطالعه، حلقه هدف روزانه، نقشه حرارتی استمرار ۲۸ روزه، امتیاز تجربه روباه (`XP`) و ثبت روزانه حس‌و‌حال با ایموجی (`😩` تا `🤩`).
- **🌿 آکادمی تمرکز و آرامش ذهن:** نکات علمی درس‌خواندن، چک‌لیست عادت‌های سلامتی روزانه و تمرین **تنفس جعبه‌ای ۴-۴-۴-۴** با انیمیشن تنفسی آرام.
- **🎨 ۷ تم از ساده تا طرح‌دار + ۴ فونت فارسی + تنظیم اندازه متن:**
  - تم‌های مینیمال (`ساده تیره`، `کاغذ کرم`) و طرح‌دار (`کلبه جنگل روباه 🌲🐾`، `کهکشان و مهتاب 🌙✨`، `شکوفه بهاری 🌸🦋`، `ذن چای سبز 🍃🌊`، `پاپ‌پاستل ⚡🎨`).
  - انتخاب از بین **۴ فونت فارسی آفلاین** (`وزیرمتن`، `بالو`، `ریدکس پرو`، `لاله‌زار`) و تنظیم اندازه نوشته‌های کل برنامه (`۸۸٪` تا `۱۲۵٪`).
- **🎵 ۷ افکت صوتی استودیویی + امنیت PIN:** افکت‌های کالیمبا، چنگ بهاری، ماریمبا، تشویق روباه، زنگ ذن، جرقه جادویی و حباب، به همراه قفل `PIN` با هش محلی `SHA-256` و خروجی/بازیابی `JSON`.

## 🇺🇸 English Overview

**Fox Planner** is a distraction-free, **100% offline-first** productivity, focus, multimedia study notebook, and mental-wellness app built for mobile devices with full **Persian (RTL) & English (LTR)** support.

### 🌟 Core Highlights

| Module | What You Get |
| :--- | :--- |
| **📋 3-Part Planner** | Clean workspace with **Daily Tasks**, a built-in **Jalali (Persian) Calendar** with national/student occasions & custom exams, and **Smart Reminders** with customizable timing, repeat rules, and playful/calm alert tones. |
| **🍅 Linked Pomodoro** | Classic `25/5`, Deep `50/10`, Sprint `15/3`, or custom intervals tied directly to tasks, plus live distraction tracking. |
| **📓 Multimedia Notes** | Rich block editor supporting headings, golden highlights, checklists, photos, videos (`expo-video`), and document attachments (`PDF`) stored locally offline. |
| **📊 Animated Analytics** | Smoothly animated Fox XP rank bar, daily goal ring, interactive 7/14-day bar charts, 28-day heatmap, and emoji Mood Journal waves. |
| **🌿 Wellness Academy** | Organized into 3 calm panels: science-backed study guides, daily health habit checklist, and animated `4-4-4-4` box breathing. |
| **⚙️ Corner Hub Menu** | Uncluttered top-right settings hub containing **7 Minimal & SVG-Patterned Themes**, **4 Bundled Persian Fonts + Global Text Size Scaler**, **7 Studio `.wav` Sound Packs (`expo-audio`)**, offline `SHA-256` PIN lock, JSON backups, and automatic GitHub Release update checks. |

## 🛠️ Tech Stack & Local Development | توسعه و اجرا

- **Framework:** React Native `0.88` + Expo SDK `58` + TypeScript
- **Audio & Media:** `expo-audio`, `expo-video`, `expo-image-picker`, `expo-document-picker`, `expo-notifications`, `expo-haptics`
- **Typography & Graphics:** `react-native-svg`, `@expo-google-fonts/{vazirmatn,baloo-bhaijaan-2,readex-pro,lalezar}`
- **Security & Testing:** `expo-crypto` (`SHA-256` PIN hashing), `node --test` unit test suite (`9/9` domain checks passing)

```bash
# Install dependencies
npm install

# Run TypeScript check & domain unit tests
npm run typecheck
npm test

# Start Expo dev server (Expo Go / Web)
npx expo start --clear
```
